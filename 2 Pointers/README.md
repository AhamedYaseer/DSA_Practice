# Two Pointers

This folder contains LeetCode problems solved using the Two Pointer
technique.

## Common Patterns Used

- Opposite-End Two Pointers
- Left and Right Pointers
- Inward Traversal
- Sorted Array Optimization
- In-Place Array Processing
- Duplicate Handling
- Two-Pointer Water Trapping

## Problems Covered

| Problem | Main Technique |
|---|---|
| Reverse String | Two Pointers, In-Place Array Processing |
| Valid Palindrome | Two Pointers, Inward Traversal |
| Two Sum II | Two Pointers, Sorted Array Optimization |
| Squares of a Sorted Array | Two Pointers, Opposite-End Traversal |
| 3Sum | Sorting, Two Pointers, Duplicate Handling |
| Container With Most Water | Two Pointers, Opposite-End Traversal |
| Trapping Rain Water | Prefix/Suffix, Two Pointers, Inward Traversal |

## Complexity Goal

Two pointers are commonly used to reduce O(n²) approaches to O(n)
by processing elements in a single traversal.

For problems that require sorting first, the total complexity may be
O(n log n) because of the sorting step.

Typical target:
- Time: O(n) after sorting when applicable
- Space: O(1) auxiliary space
